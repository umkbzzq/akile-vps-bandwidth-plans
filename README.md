## 满速能跑多久，一条公式自己算

**流量(GB) ÷ (带宽 Mbps ÷ 8) ÷ 3600 = 满速小时数**

三个结果记住就够用：

- 1Gbps 满速约 125MB/s，1TB 流量跑满约 2.3 小时
- 10Gbps 满速约 1.25GB/s，同样 1TB 只够跑 14 分钟
- 100Mbps 满速跑满 1TB 约 23 小时

代进 Akile 的套餐：LAXLite-One 的 5Gbps 跑 1TB，1000 ÷ 625 ≈ 1600 秒，27 分钟；HKLite-Mini 的 1Gbps 跑 2.5TB，约 5.6 小时；HKLite-Pro 的 2Gbps 跑 30TB，约 33 小时。同样标着"大带宽"，前两个是短跑，最后一个是长跑。

拿这条公式对照自己的业务。日均 20GB 的下载站，一个月 600GB，LAXLite-One 的 1TB 额度够用，而且用户集中晚上下载时，5Gbps 端口扛得住并发。日均跑到 200GB 以上，5TB 起的档位才不至于月中就撞墙。

## 回国线路的钱花在哪：洛杉矶内部的定价倒挂

LAXPro-Light 只有 300Mbps，价格是 LAXLite-Starter 的 1.25 倍，流量只有它的十七分之一。这个倒挂不是定价失误。

较早的产品说明里，LAXPro 系列标注的是电信 CN2 GIA、联通 9929、移动 CMIN2 的回国优化线路，面向国内访客。这类线路每 Mbps 的成本比普通国际出口高一两个数量级，所以同样价钱只能买到几十分之一的带宽。当前页面是否还这样标注，下单前扫一眼套餐说明。

同样的地理成本逻辑在全球范围内都成立。Kamatera 有一款配置完全相同的机型，美国区给 5TB 流量 $4/月，香港区同价只给 1TB，5 倍差距就是地理位置的价格。Akile 内部也能看出来：洛杉矶 5Gbps 配 1TB 卖 ¥8.88，香港 1Gbps 配 2.5TB 要 ¥24.99，香港给的流量反而更少，因为带宽资源本身就贵。

访客在国内，50Mbps 的 CN2 GIA 常常好过 500Mbps 的普通国际线路，普通出口在晚高峰会拥堵，标 1Gbps 实际跑出几十兆的情况不罕见。访客在海外，就纯看带宽和流量的性价比，别为用不上的回国优化付钱。

## 晚高峰测一次，再决定付多久

白天的测速数据参考价值有限。普通国际线路在 19:00 到 23:00 的拥堵程度可能是白天的好几倍，你要看的是这个时段的实际下行速度，不是凌晨三点跑出来的漂亮数字。

下单前的清单，按顺序过一遍：

1. 先月付，别一上来就年付。¥8.88 那种折算价是按年付算的，月付单价会高一些，但换来的是一个月内随时可以走人。
2. 开通当天做三件事：晚高峰测速、ping 你目标用户所在地区的延迟、跑一遍实际业务的压力测试。24 小时退款窗口就这么多时间。
3. 确认续费价。活动价和常规价往往不是同一个数字，订单页会写清楚。
4. 算清流量。用上面那条公式，把月流量除以满速速率，看看你的业务是不是会在月中就限速。
